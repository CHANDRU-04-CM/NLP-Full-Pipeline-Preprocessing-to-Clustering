# NLP-Full-Pipeline-Preprocessing-to-Clustering
This repository demonstrates a complete Natural Language Processing (NLP) pipeline using Python.

The project includes:

• Text preprocessing (punctuation removal, tokenization, stopword removal, stemming, lemmatization)
• Feature engineering using Bag of Words and TF-IDF
• Cosine similarity calculation between sentences
• Supervised learning using Naive Bayes for text classification
• Unsupervised learning using K-Means for text clustering

This assignment showcases how raw text data is transformed into meaningful numerical representations and used in machine learning models for classification and clustering tasks.

Technologies Used:
Python, NLTK, Scikit-learn

This project is part of an NLP course assignment focusing on real-world text processing workflows.
